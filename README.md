The safety label that should come printed on every human being.

## The entry

**WARNING: human contains unpatched optimism, runs on caffeine, and will confidently explain things it just Googled.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
